> 复现对象：论文 §7.4 Winterfell 行（沙盒值：prove 197.6 ms / verify 1.04 ms / proof **57,589 B**）
> 环境：WSL2 x86-64（13th Gen i7-13650HX，20 线程），rustc 1.98.1（与沙盒同版）；winterfell 0.13.1（当日全新解析，Cargo.lock 生成于本机）
> 甲组 = 本机重建二进制（`wf-audit/`，`cargo run --release`，6 次）；乙组 = 沙盒原版二进制（`wf-audit-bin`，sha256 `db0d8270…`，`chmod +x` 后直接运行，10 次）

| | 甲组（重建） | 乙组（原版） | 沙盒报告值 |

## 2) 证明尺寸：非定值（关键发现）

21 次运行观察到 **7 个不同结果**（56.2–58.4 KiB），且**相同证明在甲、乙两组间字节级重现**：

| 证明 sha256 前缀 | 尺寸 (B) | 甲组出现 | 乙组出现 |
|---|---|---|---|
| `4f8bb6c8…` | 57,656 | 1 | 3 |
| `a46110b2…` | 58,647 | 0 | 1 |
| `52f26ec6…` | 58,906 | 1 | 1 |

| `396161c9…` | 59,382 | 4 | 3 |
| `411cccc4…` | 59,830 | 0 | 1 |
| （沙盒原件，哈希未记录） | 57,589 | 0 | 0（沙盒 5 次全同） |

- C_T = `0x844ff2e16c353227` 在所有运行中恒定（trace 确定性）✅
- 同一证明（如 `396161c9…`）同时出现在**重建**与**原版**二进制上 → **跨构建字节级可复现** ✅

**机制（已定位到源码）**：wf-audit 启用 winterfell 的 `concurrent`（rayon）特性；PoW grinding 由 `winter-prover-0.13.1/src/channel.rs` 的 **`find_any`（并行，第 180 行）** 选出合法 nonce（顺序版在 174 行）。线程调度 → 不同 nonce → transcript → 查询位置采样 → 去重后开放位置数不同 → 尺寸小幅浮动（±~2 KB）。合法 nonce 空间小 → 结果会重现。**沙盒"5×57,589、尺寸确定"是单调度路径的巧合。**

## 5) 线程数敏感性（2026-10-02 追加 · 关键）

prove 时间对 rayon 线程数**高度敏感**（同一台机器 A/B 实测）：

| 配置 | prove（中位） | proof 结果稳定性 |
|---|---|---|
| 默认线程（本机 20） | ≈**130 ms** | 尺寸/字节每次变动（`find_any` 竞争） |
| `RAYON_NUM_THREADS=2`（原生） | ≈**37 ms** | **稳定**：57,656 B / `4f8bb6c8…`（5/5 一致） |
| 容器 2c/4g + `RAYON_NUM_THREADS=2`（v4 canonical） | ≈**37–40 ms** | **稳定**：同上（5/5 一致） |

- 结论：winterfell `concurrent` 在小迹（3×4096）上 20 线程产生 ~3.5× 并行开销；**要稳定复现请设 `RAYON_NUM_THREADS=2`**（此时 grinding 结果也趋于确定）。
- 沙盒值 197.6 ms 为其环境值（2 核，未记录线程配置；本机同线程数下 ≈37 ms，差距来自该环境 CPU 速度）。
- **论文若引用本演示耗时，必须连带注明线程配置**——文本相修订项（与 §7.4 "尺寸确定" 一并处理）。
